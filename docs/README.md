# Reference

The user-facing interface of hatchrun, kept next to the code that
implements it.

- [Command line](cli.md): `hatchrun validate` and `hatchrun convert`.
- [Workflow configuration](config.md): `.hatchrun/config.yml`, its jobs,
  workflows, triggers, steps and expressions.
- [HTTP API](http-api.md): the Worker routes, the app's JSON API and the
  `/api/ci/` run API.

The [README](../README.md) covers what each component is and how to
deploy it. The files under [`superpowers/`](superpowers) are the design
notes and implementation plans written before the code; they are
history, not the reference, and may describe work that has changed.
